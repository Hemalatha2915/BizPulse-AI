# BizPulse AI
### Business Sales Analytics & Profitability Analysis

## About the Project
BizPulse AI is a business analytics project that analyses sales data to identify profitable products, calculate revenue and profit, and generate actionable business insights.

## Objectives
- Analyse product-wise sales performance
- Calculate total revenue and profit
- Compare revenue and profit across products
- Calculate product-level profit margins
- Summarise key business performance indicators
- Validate data quality

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Results
- Total Revenue: ₹242,000
- Total Profit: ₹53,050
- Overall Profit Margin: 21.92%
- Products Analysed: 4

## Key Insights
- Laptop generated the highest total profit: ₹24,000.
- Mouse had the highest product profit margin: 50%.
- Product profitability differs from total sales revenue.

## Dataset
This project currently uses a small, manually created sample dataset for learning and demonstration. The results are illustrative, not real company performance.
